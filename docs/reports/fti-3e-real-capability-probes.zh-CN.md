# FTI-3E 真实模型能力探针报告

日期：2026-09-02

## 本轮目标

把设置页原有的“按模型名称进行静态能力提示”升级为可由用户主动触发、可核验且可记录成本的真实任务能力测试，同时确保普通配置读取和保存不会自动消耗模型额度。

## 已完成

1. 每个任务模型均提供独立的“真实测试此任务”入口；展开任务行只读取静态判断和本机历史，不调用模型。
2. 论文分析、翻译、推荐和科研问答验证最小文本指令遵循能力。
3. 查询规划要求模型返回指定 JSON，并在服务端实际解析字段，不把“有响应”误判为结构化输出通过。
4. 视觉任务发送一张内嵌红色测试图，只有模型正确识别主色才通过，测试图片不读取用户文件。
5. 出图任务真实调用一次图像生成接口；点击前明确二次提示可能产生费用。
6. 每次测试记录供应商、模型、任务、能力、UTC 时间、耗时和供应商返回的输入/输出/总 Token。
7. 最近一次结果写入每用户本机运行目录；API Key、响应正文和生成图片 URL 均不进入历史文件。
8. 测试使用隔离配置：请求字段、任务专用配置、主模型和备用模型仅在提供商匹配时继承凭据，禁止跨供应商复用 Key。
9. 中英文设置页均已补齐任务名称、说明、静态判断、测试按钮、耗时和 Token 结果。
10. Embedding 延续独立的“测试语义模型”入口，并显示向量维度与输入 Token；不与聊天能力混在同一探针中。

## 真实调用验收

- 当前本机主模型：智谱 `glm-5.2`。
- 测试任务：查询规划 / 结构化输出。
- 结果：通过，模型返回了字段正确且可解析的 JSON。
- 端到端耗时：`13.718s`。
- 供应商返回 Token：输入 `23`、输出 `9`、合计 `32`。
- 本轮没有触发视觉、出图或 Embedding 的真实调用。

## 自动验证

- 后端非联网测试：315 项通过，27 项联网测试未执行。
- 能力探针回归覆盖结构化解析、真实图片输入、历史脱敏、同供应商凭据继承与跨供应商隔离。
- 前端自动测试：21 项通过。
- TypeScript 类型检查通过。
- 前端生产构建通过，共转换 1531 个模块。
- 本机后端健康检查 HTTP 200；设置页中英文与刷新后历史回显均通过浏览器验收。

## 明确边界

- “通过”只证明该模型在当前提供商、当前配置和测试时刻完成了一个最小任务，不等于完整业务质量评测。
- Token 完全采用供应商响应；服务商不返回 usage 时显示 0，不进行伪造估算。
- 图像生成接口通常不返回文本 Token，而且可能按图片计费，因此页面单独提示。
- 当前智能体工具执行由 ScholarNova 后端编排，不依赖模型原生 function calling，因此本轮不增加一个会造成误解的“工具调用能力”徽章。
- 测试结果只保留最近一次本机记录，不上传云端或 GitHub。
