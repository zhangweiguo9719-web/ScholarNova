# v1.2.2 智能体身份与能力问答修复

验证日期：2026-09-09。此报告只说明本次验证范围，不代表所有模型、网络环境或自然语言表述均已通过。

## 问题与原因

用户问“你可以做什么？”，桌面版却查询本地论文，在空知识库下显示“材料不足”。已有产品帮助分支只识别部分带产品名的使用问题，未覆盖这类常见身份和能力表达；这是应用意图分流缺陷，不是据此可以判定的模型能力或 API Key 问题。

## 精准改动

- 在检索和模型调用之前识别常见中英文身份、能力、操作说明请求，明确介绍 ScholarNova 的功能及材料边界。
- 对完整请求匹配，防止把“论文中智能体能做什么”“智能体是什么”等概念问题误当产品帮助；当前问题优先，不让旧科研对话覆盖用户的新意图。
- 产品指南不要求论文引用，零模型调用、零 Token；科研问题继续遵循检索、证据、模型路由及引用检查流程。
- 前端原本支持产品指南显示，本次补齐界面和重新载入后的回归验证，没有重写用户对话历史。
- 更新为 v1.2.2，统一后端接口版本与包版本。不修改 appId、用户目录、已有模型配置或个人数据库。

## 用户复验步骤

1. 升级并启动新桌面版，进入“智能体”，重新发送“你可以做什么？”。应说明自己是 ScholarNova 科研助手，展示产品指南，不出现“材料不足”标记。
2. 再问“你是谁”“你是个啥”“Who are you?”，应识别为身份/帮助请求，Token 为 0。
3. 在曾经讨论论文的对话中再问“目前这个智能体怎么使用呢？”，应回答使用步骤，不接着总结旧论文。
4. 问“分析这篇论文的方法”或“论文中智能体能做什么”，应进入科研流程。没有证据时应明确材料不足，而不是用产品介绍充数。
5. 关闭并重开应用，检查原有文件夹、对话和模型配置保留；历史错误回答不会被自动改写。

## 限制与费用

内置帮助仅说明应用已实现的功能，不是自由聊天模型，也不报告猜测的底层模型身份。复杂混合意图仍可能需要用户拆分问题。引文覆盖检查不能证明结论语义正确，关键科研结论仍需回看原文。

帮助回归没有调用付费模型，Token 为 0 是刻意的成本控制，不能把它用作科研推理成本的评测成绩。本轮额外真实模型测试记录供应商返回用量 **588 Token**；超时请求没有返回 usage，因此这不是保证完整的供应商账单。Codex 平台未提供本轮精确 Token 账单，不报告虚构数字。
