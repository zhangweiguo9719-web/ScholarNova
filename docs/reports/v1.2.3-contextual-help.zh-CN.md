# v1.2.3：上下文使用指导与桌面启动修复

## 解决的问题

“我该如何使用你”过去未命中产品帮助规则，错误进入论文检索；无文献时提前返回“材料不足”，回答模型根本没有被调用。本次将使用指导与科研证据问答分开，同时恢复隐藏窗口的正常显示。

## 处理方式与边界

- “我该如何使用你”“我应该怎么用你”“如何与你协作”等明确使用问题直接进入帮助。
- “那下一步呢”“然后呢”等短追问仅在当前会话最近用户问题可追溯为帮助时承接上下文；中间切换到科研问题后，不沿用旧帮助主题。新会话不读取其它会话。
- 帮助模型使用内置指南、最近 4 条消息（每条最多 1000 字符）和用户选中的来源开关。开关不是连接状态，不将“选中 Zotero”说成“已连接 Zotero”。不查询或上传知识库、论文全文、Zotero 文献或 API Key。
- 使用设置中“智能体”任务的模型，最多一次尝试、12 秒等待预算、800 输出 Token；不自动改用其它供应商。未配置模型、初始化失败、超时、空回答或伪造论文引用时，改用内置指南，仍保留已收到的用量。
- 科研问题保留原文证据与引用约束。内置帮助和 AI 使用指导均不伪装成论文证据。
- 意图入口仍为可测试的规则分流，不是开放式自主执行 Agent；模型负责基于指南理解和回答。对任意新表达的完美识别、所有步骤的语义真实性均不作保证。

## 真实模型测试

2026-09-09 使用本机已保存的 SiliconFlow / `Qwen/Qwen3.6-27B`，在临时空数据库中通过实际后端接口验证；没有读取私人论文，没有修改原模型配置。

| 我该如何使用你 | 触发模型超时，正确返回内置使用指南 | 12.25 秒 | 0（未返回用量） |

此组共记录 **991 Token**。超时请求未返回用量不代表供应商一定未计费；应以供应商账单为准。这是功能验收，不是检索 F1 评测，也不代表所有模型或全部问法稳定。

### 安装后的真实桌面问答

使用 Windows 桌面程序新建独立对话，先问“我该如何使用你”，再追问“那下一步呢”。两次都进入 `product_help`，实际尝试 SiliconFlow / `Qwen/Qwen3.6-27B`，均未在本轮等待预算内完成。界面正确显示“内置帮助兜底”“模型尝试 1 次”及可读使用步骤，没有误报“材料不足”或执行论文检索。测试对话保留在本机，已有对话不改写。

这验证了安装版的帮助分流、上下文入口与失败兜底，**没有证明安装版 AI 回答的稳定性**。上文成功的 AI 连续追问来自独立后端接口测试；本次两个桌面请求均未返回用量，因此功能测试合计可核对的供应商用量仍为 **991 Token**，不是实际账单上限，也不是 Codex 平台用量。供应商与本机网络延迟仍需关注；内置兜底会重复基础指南，不具备模型完成回答时的个性化连续指导能力。

## 你可以这样验收

1. 设置中检查“智能体”任务选择自己的可用模型；不需要改分析、视觉或出图任务。
2. 新建一个智能体对话，即使没有论文，也问“我该如何使用你”。应显示“AI 使用指导”，模型失败时应为“内置帮助兜底”，两者都不应提示材料不足。
3. 在同一对话问“那下一步呢”，应承接使用流程；再建一个空对话，不应带入上一对话的步骤。
4. 问“论文中的智能体有什么实验结论？”；无证据时必须说明材料不足，而不是拿产品说明编造实验结论。
5. 在独立测试配置中停用模型后重复第 2 步，仍应看到可读操作指南。不要为了测试清空日常使用的 Key。
6. 退出再通过桌面图标打开，确认窗口正常出现。旧对话中的错误回答不自动改写，需重新发送问题。

## 未改变的内容

个人 API Key、论文、知识库、研究路线与已有对话不清空；帮助请求不会自动写入 Zotero，也不会替用户登录图书馆。模型/API 网络延迟仍取决于供应商与本地网络。
