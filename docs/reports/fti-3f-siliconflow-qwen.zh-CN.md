# FTI-3F：硅基流动 Qwen 接入与真实调用验证报告

日期：2026-09-03

## 阶段结论

ScholarNova 已将硅基流动作为独立模型提供商接入，不再要求用户把它伪装成“自定义 OpenAI 兼容接口”。聊天模型、视觉能力判断、Embedding、任务路由、连接测试和真实能力探针均能识别 `siliconflow`，同时继续遵守不同提供商之间的凭据隔离。

本阶段用用户明确授权的本机 API Key 完成了真实调用。Key 只在测试请求期间通过 HTTPS 发送给硅基流动，没有写入仓库、README、阶段报告或 Git 提交，也没有覆盖用户现有的智谱主模型配置。

## 接入内容

- 设置页新增 `SiliconFlow（硅基流动）`，默认地址为 `https://api.siliconflow.cn/v1`。
- 默认文本模型为 `Qwen/Qwen3-8B`，并提供 Qwen3 Instruct、Qwen3.5 与 Qwen3-VL 常用候选项。
- 语义检索配置新增 Qwen3 Embedding 0.6B、4B、8B 候选项。
- 查询规划、论文分析、翻译、推荐和问答可通过现有任务路由选择硅基流动模型。
- Qwen3 的短连接测试与结构化能力探针默认关闭思考模式，避免把短请求预算全部消耗在隐藏推理上。
- 普通业务调用继续使用既有连接重试与备用模型机制；能力探针保持单次请求，以便真实暴露所选模型当时的可用性和延迟。
- README 与 API Key 指南补充了硅基流动的申请入口、官方文档、Base URL 和本地配置示例。

2026-09-02 调用硅基流动模型列表成功，当时返回的可用模型中检出 44 个 Qwen 相关 ID。模型目录会由服务商调整，产品中的候选列表只是常用快捷项，实际使用前应以[硅基流动模型广场](https://cloud.siliconflow.cn/models)为准。

## 使用建议

用户可在“设置 → LLM 模型配置”中选择 `SiliconFlow（硅基流动）`，填写自己的 Key 后先执行连接测试，再按任务配置查询规划、分析、翻译或问答模型。需要多模态时应选带 `VL` 的模型，并执行视觉真实能力探针；普通 Qwen3 文本模型不应被标记为已验证的视觉模型。

官方入口：

- [API Key 控制台](https://cloud.siliconflow.cn/account/ak)
- [硅基流动快速开始](https://docs.siliconflow.cn/cn/userguide/quickstart)

## 阶段边界

本报告证明的是“硅基流动 Qwen 已能在 ScholarNova 中被选择、隔离配置并真实调用”，不等于所有 Qwen 模型在任何时间都可用，也不代表已完成竞赛 F1 评测。模型质量、费用、并发限制和服务稳定性仍需针对具体任务与正式数据集持续评估。
