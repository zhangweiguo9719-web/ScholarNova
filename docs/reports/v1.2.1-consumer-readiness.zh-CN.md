## 本轮变化

- 检索结果将文字相关度与综合推荐分拆开，高被引不再被直接当成高相关。
- 离开搜索页面或开始新搜索后，旧响应不得重新填入结果；同一搜索中切换论文仍保留已完成的分析。近期检索词仅在当前窗口保存。
- 引用不完整时最多修订一次；失败则给出来源摘录，明确区分“模型不可用”与“引用检查未通过”。引用检查不等于科学事实核验。
- 限制智能体单路调用与修订时间，保留服务商返回的 Token 统计；Anthropic 内部重试参数不再进入请求正文。
- 桌面程序使用独立的临时进程令牌连接本地后端，令牌不进入网页或用户配置；外链协议、代理来源和静态文件路径有校验。
- Windows 内置运行环境；Mac 使用原生 Intel/Apple Silicon 构建，保留 Python 打包文件的符号链接并使用本地 ad-hoc 签名。
- 中英文 README 改为一个四宫格，安装、API 申请、开发和历史评测分开说明。
- Word/PDF 研究路线导出统一转义标题、描述和模型内容，过滤图片协议并禁用文档脚本，避免模型输出成为可执行内容。
- 便携版退出检查发现：页面全部完成后，中途断开的后端请求重复发送 HTTP 响应头，弹出错误框而无法退出。代理层现区分未发送、已发送和已关闭响应，并在客户端断连时关闭对应上游请求。

## 用户可复现的完整试用案例

1. 下载适合 CPU 的安装文件。Windows 安装版双击安装，Mac 将应用拖入 Applications。首次启动没有预置私人密钥和知识库。
2. 设置 → 填自己的模型服务商、模型名、API 地址及 Key → 测试连接 → 保存。文本模型和出图模型分别配置；不要把聊天模型填到出图任务。
3. 搜索 `traffic flow prediction graph neural networks`。观察来源名称、耗时、限流/失败说明；同样的词再次搜索应产生一次新检索，而不是无反应。
4. 打开论文 A，运行分析，再选 B，再回 A：当前搜索内的已完成分析应保留。若没有全文，页面应明确说明材料范围，不得声称已读完整 PDF。
5. 上传你有权使用的 PDF。上传过程中切换搜索或离开页面，旧上传完成不能把旧分析写入新会话。
6. 将有价值的分析保存到知识库分类。进入智能体，新建研究方向文件夹与对话，询问“目前这个智能体怎么使用”：应返回产品使用指引，不应引用无关论文作答。
7. 针对已存材料提问并检查来源卡片；关闭模型或使用不可用测试地址时，应给出有边界的失败提示或来源摘录，不编造文献。
8. 本机打开 Zotero，在高级设置允许其他程序通信；在 ScholarNova 检测并选择分类。读取与写入分开操作，实际导入后去 Zotero 核对条目及目标分类。
9. 退出应用重启：知识库和模型设置保留，临时检索结果不应重新出现。覆盖安装升级前先备份本地数据目录。

## 仍需注意的边界

- **发行签名**：Windows 未做商业代码签名，Mac 的 ad-hoc 签名不是 Developer ID 签名或 Apple 公证，系统可能提示风险。需要开发者证书才能完善这部分；不建议全局关闭系统安全机制。
- **依赖许可**：PyMuPDF / MuPDF 的 AGPL 或商业许可义务不能被项目 MIT 声明替代。正式安装包发布已增加许可确认闸门，等待所有者选择并完成对应方案。
- **外部服务**：限流、额度、网络代理和服务商故障仍可能影响响应。有限重试不能保证第三方始终可用。
- **全文和授权**：没有绕过付费墙、验证码或学校身份验证。用户授权取得的 PDF 可导入；没有全文或图片时必须显示实际材料范围。
- **密钥**：本地配置文件尚未接入操作系统钥匙串。请保护设备账户与备份，不要公开配置文件。调用模型会把所选材料发送给该服务商。
- **Zotero**：不同版本的 Connector 写入能力与集合定位仍需在目标用户环境检查；不能把“读取连接正常”当成“写入成功”。RIS/BibTeX 导出是通用替代方案。
- **指标**：未重跑 AstaBench/PaSa；旧子集 F1 不代表本版本正式竞赛成绩，也不能与 SPAR 不同设置直接排名。
- **测试范围**：自动化非联网回归不等于大量真实用户长时间试用。Mac runner 启动检查不等于个人 Mac 实机完整验收。

## 版本与回退

代码、安装程序与文档版本应一致。不要覆盖已有 Git 标签；修复发布失败后采用新的补丁版本。安装包与校验和仅以 [GitHub Releases](https://github.com/zhangweiguo9719-web/ScholarNova/releases) 为准。

备份：Windows `%APPDATA%/scholarnova-desktop`；macOS `~/Library/Application Support/scholarnova-desktop`。卸载/升级前关闭程序并备份整个目录；旧版本恢复只应用其兼容的备份。

本次 Codex 会话没有精确计费 Token 统计接口，因此不提供推测数字。应用自身的模型 Token 以服务商 usage 响应为准；本轮模拟测试不产生模型调用费用。
