# ScholarNova v1.2.5 — Assistant recovery and preserved usage

修复使用指导超时后的恢复体验。模型使用精简产品说明和有限的当前对话上下文，继续尊重设置中的智能体模型；等待预算为模型阶段 60 秒，最多输出 320 Token。

Product help uses a compact guide and bounded conversation context, with a 60-second model-stage budget and a 320-token output cap. It preserves the Assistant model selected in Settings.

- 最新一条失败指导可点击“再次调用 AI”；复用原问题并替换失败卡片，不重复发送问题、不改写其后的历史。
- Retry AI reuses the original question and replaces only the latest failed help answer; double-clicks do not create multiple requests.
- 重试保留前次调用与已返回 Token，缺失用量仍标记未知；当前回答与历史尝试分开展示。切换对话后结果仍归属原对话。
- Earlier attempts and their known usage remain available across retries. Missing usage stays unknown, and replies remain attached to their original conversation.
- 科研问答仍受文献证据与引用约束，产品使用指导无需先导入论文。
- Research answers retain their evidence and citation requirements; product guidance does not require papers.
- Windows 便携版采用直接解压，以更大的下载体积换取更少的首次解压工作；日常使用仍推荐 Setup 安装版。
- The Windows portable build uses direct extraction rather than nested LZMA compression. The download is larger; Setup remains recommended for everyday use.

## 验收与升级 / Validation and upgrade

源码服务使用真实 SiliconFlow / Qwen/Qwen3.6-27B 完成连续三轮指导，记录 2,015 Token。这是功能验收，不是新的检索 F1 成绩，也不保证供应商始终可用。完整结果和安装检查见[验收报告](https://github.com/wei9719/ScholarNova/blob/v1.2.5/docs/reports/v1.2.5-assistant-retry.zh-CN.md)。

Quit ScholarNova before upgrading. Your model configuration, papers and conversations are stored outside the installation directory. Install the new Setup package on Windows or the matching DMG on macOS; check this release's actual assets and SHA256SUMS.txt. Existing messages are preserved; retry the latest failed help turn or start a new conversation to verify the update.

Windows and macOS publication is gated by native platform startup tests, matching corresponding source and package notices. Commercial Windows signing and Apple notarization are not configured.
