# ScholarNova v1.2.3 — Contextual product guidance

## 更新 / Changes

- 使用指导支持“我该如何使用你”及同一会话的“那下一步呢”；AI 基于内置指南和有限近期上下文回答，科研问题继续要求真实证据。
- Help uses the configured Assistant model with one attempt, a 12-second budget and at most 800 output tokens. Missing configuration, timeouts and invalid answers return the built-in guide, with measured usage retained.
- 区分 AI 使用指导和内置帮助兜底，不误报材料不足；保护不同对话间的上下文隔离。
- Restore hidden desktop windows on startup/relaunch; use the shared package version in both health endpoints.

升级后请重新提问，旧对话不改写；个人资料与 API Key 保存在安装目录之外。Re-ask after upgrading: previous answers are not rewritten.

## 验证与限制 / Validation and limits

Backend: 517 offline tests passed, 27 opt-in integration tests excluded. Desktop unit checks: 12 passed. A real Qwen help follow-up returned in 8.7 seconds with 991 reported tokens; the first request timed out and correctly returned the guide. Provider timeouts may not report billable usage. This is not a new F1 benchmark. See the [validation report](https://github.com/wei9719/ScholarNova/blob/main/docs/reports/v1.2.3-contextual-help.zh-CN.md).

## 发行 / Distribution

GitHub publication is gated by Windows/macOS builds and smoke checks plus matching corresponding source. Download only files actually present in this Release. Setup is recommended for everyday Windows use; portable cold extraction can be slow. Desktop combinations follow applicable AGPLv3 terms, while project-owned source retains MIT attribution; build-specific notices, corresponding source and checksums accompany the release. Commercial signing and Apple notarization remain unconfigured; do not disable system-wide security protections. Bring your own API Key and never publish private configuration files.
