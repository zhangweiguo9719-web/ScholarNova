# ScholarNova v1.2.4 — Help continuity and request transparency

修复使用指导的重复回复、过短超时和模型调用状态误导。下载请以本 Release 实际附件为准；源码版本号不等于安装包已经发布。

## 修复内容 / Changes

- 使用指导的模型等待预算调整为 45 秒、一次尝试，避免短超时反复返回同一份指南；不将该预算等同于端到端总耗时。
- Product guidance gets a 45-second model-stage budget and one attempt, without hidden retry multiplication.
- 结合有限近期上下文理解“这两次回答咋一样”等反馈，不把针对使用指导的追问误送到论文检索；科研问题仍需真实材料支持。
- Contextual feedback about product guidance stays in the help flow. Research questions still require evidence, and separate conversations remain isolated.
- 区分首次使用指南与重复失败后的简短说明，明确模型是否成功回答以及用户下一步可以检查什么，不反复粘贴同一篇长指南。
- Failed follow-ups receive a concise, contextual explanation rather than the same long guide. Model-generated guidance and built-in fallback remain distinguishable.
- 如实展示请求尝试和可获得的 Token 统计。未发起请求、已发起但失败、成功返回是不同状态；未收到 usage 不代表没有消耗或没有费用。
- Request attempts and reported usage remain distinct: missing usage is not proof of zero tokens or zero cost, and fallback text is not labelled as a successful model answer.

## 升级与验收 / Upgrade and validation

沿用原安装身份和独立用户数据目录，不内置或重置用户的 API Key。升级前备份个人资料；升级后重新提问，历史回答不自动改写。

The update is intended to retain the existing installation identity and external user-data directory. Back up personal data before upgrading and re-ask after upgrading; previous answers are not rewritten.

后端 582 项、前端 53 项测试通过。真实 Qwen 接口连续三轮回答成功，用时 19.89 / 7.70 / 8.83 秒，记录 2587 Token；更早的开发验证另外记录 2319 Token，其中一次回答未通过校验。最终提示词和安装版验收、失败样本与限制均见[完整测试报告](https://github.com/wei9719/ScholarNova/blob/main/docs/reports/v1.2.4-assistant-calls.zh-CN.md)。这些是功能测试，不是新的 F1 成绩。
