# ScholarNova v1.2.2

## 智能体使用引导与工作流修复

- 修复“你是谁”“你可以做什么”等中英文问题被误判成论文检索、显示“材料不足”的问题。现在直接返回内置身份、能力及操作指南，不需要知识库或模型调用。
- 科研问题继续检索真实材料、展示来源并检查引用；不因为论文中出现“智能体”就改答产品介绍。
- 指南回答保存后仍按产品指南展示，旧聊天记录保留原样；升级后请重新发送原问题验证。
- 包含 Zotero 目标集合回读核验、图书馆代理失败重试、研究路线内容与图片状态持久化、图形规划的共享模型路由及 Token 统计修复。

## Assistant guidance and workflow fixes

- Route common identity, capability and how-to requests to built-in product help before research retrieval. No paper import or model call is needed for these questions.
- Keep research questions evidence-bound, including questions discussing agents in papers. Preserve the guide type across saved conversations.
- Include verified Zotero metadata saves, direct portal retry after proxy failure, research-route content/image-state fixes, shared diagram-planner routing and accurate architecture-extraction token accounting.

Windows 10/11 x64 installer/portable and macOS 13+ Intel/Apple Silicon DMG/ZIP are published only after native build and smoke-test gates pass. Actual available files are listed in this Release's Assets. No private API keys or personal databases are included. Existing user data is stored outside the installation directory; quit the app and back it up before upgrading.
