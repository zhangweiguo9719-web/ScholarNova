# ScholarNova v1.2.1

Community desktop build using the selected AGPL open-source route for the combined distribution. Publication requires automated source and notice verification plus native Windows and macOS packaged-app smoke tests. See the [distribution requirements](https://github.com/zhangweiguo9719-web/ScholarNova/blob/main/docs/DESKTOP_LICENSE_REVIEW.md); downloadable files are listed in this version's actual Release assets.

Windows 10/11 x64 installer and portable app; macOS 13+ Intel and Apple Silicon DMG/ZIP.

- Fixed sentence-level citations in deterministic evidence excerpts and distinguished model failure from citation-check failure.
- Bounded Assistant calls and citation repair; preserved provider-reported usage.
- Separated textual relevance from combined ranking and citation impact.
- Prevented late search and paper-detail responses from replacing the current session.
- Reorganized bilingual README screenshots and installation/API guides.
- Fixed macOS icon sizing and native backend architecture; added clean-profile packaged-app smoke tests and SHA256 checksums.
- Updated Electron and frontend runtime dependencies.
- Secured Word/PDF research-route exports against embedded scripts and unsafe image URLs.
- Fixed desktop exit errors when an in-flight backend response is interrupted, with portable-app exit checks in the release gate.

These community packages are **not commercially signed or Apple-notarized**. The operating system may require explicit approval. No private API keys or personal database are bundled. Configure your own keys after installation.
